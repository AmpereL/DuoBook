# 逻辑阅读 {{VERSION}} · 公开版

本安装包不包含开发者私人 API Key、模型预配置、书籍、笔记或用户数据库。首次启动提供演示书和本地阅读模式；远程模型及 MiMo 语音需填写你自己的 Key。

## 适用平台

- Apple Silicon（M1 / M2 / M3 / M4 等 ARM64）Mac。
- 应用最低系统版本为 macOS 13；完整启动回归在 macOS 15 完成，macOS 13 真机仍待验收。
- 此次不提供 Intel Mac、Windows 或 Linux 桌面安装包。

## 安装

1. 打开 `LogicReading-{{VERSION}}-macOS-arm64.dmg`。
2. 把“逻辑阅读”拖入 Applications（应用程序），然后从应用程序目录启动。
3. 无需自行安装 Python、Node.js 或启动后端服务。

本包为 ad-hoc 签名，未进行 Developer ID 签名和 Apple 公证。其他 Mac 首次打开时可能显示无法验证开发者；请先核对来源与 SHA-256，再根据 macOS“系统设置 → 隐私与安全性”的提示手动处理。macOS 13 真机未测试，不应将此包描述为已公证或已完成所有目标系统验证。

## 首次使用

- 可直接阅读原文、使用逻辑地图、划线摘抄 / 笔记和本地系统语音。
- 本地拆分模式将整章保留为一个单元。进行语义拆分时，在右上角“模型设置”选择 OpenAI 兼容或 Anthropic，填入自己的地址、模型和 Key，测试后保存。
- 使用 MiMo 听读时，在“MiMo 语音连接”中配置自己的地址和 Key；本地系统语音无需远程 Key。
- 单行阅读支持划线笔记、全书进度、透明度及置顶；默认 ⌘⇧H 全局隐藏 / 显示，隐藏停止声音，显示不自动朗读。

## 升级与数据

保持 App ID `com.duobook.reader` 与原数据目录 `~/Library/Application Support/DuoBook/`。替换 App 不删除已有书籍、笔记或用户保存的设置；已有 `model.enc` / `speech.enc` 在原用户目录中继续使用，不会复制进安装包。

你在设置页保存的模型及语音 Key 由 Electron safeStorage 加密保存在本机。书籍、原文、笔记、位置由本地 SQLite 保存，当前不提供跨设备同步或自动更新。

## 校验

同一 Release 提供 `SHA256SUMS.txt` 和 `public-audit.json`。下载文件后，可在所在目录运行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```
