# 逻辑阅读 {{VERSION}} 私人预配置版

适用平台：macOS 13 及以上的 Apple Silicon（M1/M2/M3/M4 等 ARM64）Mac；不包含 Intel 构建。2026-09-23 已改用最低支持 macOS 11 的 Python 3.12 运行时重建后端，应用入口最低系统版本为 macOS 13。包内原生文件版本检查通过，完整启动测试在 macOS 15.7.9 通过；仍需在真实 macOS 13 机器上验收。

## 安装与使用

1. 打开 `逻辑阅读-{{VERSION}}-arm64-private.dmg`。
2. 将“逻辑阅读”拖到 Applications（应用程序）。
3. 从应用程序文件夹启动“逻辑阅读”。无需自行安装 Node.js、Python 或启动开发服务器。
4. 本版本内置用户授权的 MiMo 私人 Key，默认 Anthropic 兼容接口与 `mimo-v2.5-pro`。可在模型设置中测试连接或替换。

四款应用图标可在设置页选择，默认第 2 款。选择会更新 App 内品牌图、浏览器 favicon 和桌面运行时 Dock 图标，并在重启后保留。Finder 中的应用文件图标固定为第 2 款。

章节原文和单元原文上方提供“语音阅读”，可选本地系统语音或 MiMo，支持音色、声调、语速、开始段落及暂停/继续/停止。MiMo 优先使用独立语音 Key，可在“模型设置 → MiMo 语音连接”中替换并测试；未独立配置时才沿用解析 Key。本地声音需要系统已安装。具体操作见项目 `docs/语音阅读使用说明.md`。

点击原文上方“单行阅读”打开独立悬浮小窗，左侧把手可拖动，右侧按钮或左右键翻页，空格播放 / 暂停。MiMo / 本地语音读完当前行后自动翻到下一行。右侧“…”可设置语速、声调、音色、宽度、字号、置顶及连续朗读；Esc 收起原文并停止声音，点击“资料”手动恢复。返回完整阅读会定位当前原文。新窗口及刷新后均不自动发声。操作说明见项目 `docs/单行阅读使用说明.md`。

1.2.4 增加常驻图钉置顶按钮、Page Up / Page Down 翻行快捷键及设置内的 0–100% 背景透明度。只改变背景透明程度，文字、按钮和设置面板保持可见；透明度与置顶状态会保存。

1.2.5 修复桌面安全策略误拦截 MiMo 播放器本地 Blob 音频、导致“音频加载失败”的问题。仅增加同源与 Blob 媒体播放许可，原有 API 鉴权和网络来源限制保留。普通阅读失败后直接重试会从失败片段继续，主动选择开始段落仍优先遵从选择。

1.2.6 自动保存每本书的阅读位置。书架打开时恢复上次章节 / 单元及原文位置，单行记录字符偏移，九段区域也可恢复。继续阅读优先展示最近实际阅读的书；正常退出后重启有效，不自动发声。数据仍保存在原 SQLite 目录，升级无需重新导入书籍。

1.2.7 增加单行小窗全局隐藏 / 显示：默认 ⌘⇧H，即使其他 App 聚焦也可使用。隐藏停止朗读且不弹出主窗口，显示保留位置、保持静音且不抢焦点。“…”内可修改、关闭并保存组合键，冲突时保留原键。关闭小窗或退出 App 后释放快捷键，点击 Dock 可找回隐藏小窗。

本包为 ad-hoc 签名，未做 Developer ID 签名和 Apple 公证。下载到其他 Mac 后可能被 Gatekeeper 拦截。若弹出“无法验证开发者”，先尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”。若 DMG 本身无法挂载、提示架构不支持或应用启动报错，请记录完整提示；不要把“应用已损坏”一律当作公证问题。不要将此包描述为已公证版本。

## 私人配置与数据

本版本依用户明确要求内置解析与语音的私人初始 Key；安装包持有人可以提取并使用它们。不要上传到公共下载站。密钥本身不写入代码、本文或构建日志。用户之后在设置页保存的语音连接会加密为 `speech.enc`，独立于解析设置。

新安装仅有演示书，不含开发环境的书籍、笔记或数据库。为兼容旧版，用户数据仍保存在 `~/Library/Application Support/DuoBook/`；改名或更新应用时不覆盖此目录。设置页保存后的模型配置由 Electron safeStorage 加密存储为 `model.enc`，macOS 加密材料由钥匙串管理。内置初始配置本身仍可提取。

阅读已入库原文可离线；远程模型拆分需要网络。退出 App 时会停止本地后端；拆分期间退出会中断任务，当前版本尚无任务恢复功能，建议等待完成后退出。

## 构建与正式签名

在 ARM64 Mac 上安装 npm 依赖并用 `uv venv --python 3.12 .venv-macos13` 创建兼容环境，再运行 `uv pip install --python .venv-macos13/bin/python -r services/api/requirements.txt PyInstaller==6.22.3`。执行 `npm run package:mac`；此命令现在从 `.venv-macos13` 冻结后端，避免把构建机 macOS 15 的 Homebrew Python 模块带进安装包。图标及打包辅助脚本仍使用项目 `.venv`。构建脚本会读取本机、被 Git 忽略的 `services/api/data/model-defaults.json`；该私人打包命令明确开启 Key 包含开关。

`desktop/electron-builder.yml` 管理 DMG、ZIP、应用图标与签名权限。当前 `identity: '-'`、`notarize: false`，不能当成正式公证配置。取得 Developer ID Application 证书和 Apple 公证凭据后，应改用实际签名身份并启用 notarize，在本机重新构建并执行 `codesign`、`spctl` 和 `xcrun stapler validate` 验证。凭据通过环境变量提供，勿写入仓库。

尚未配置自动更新服务器或 App Store 发布流程。
