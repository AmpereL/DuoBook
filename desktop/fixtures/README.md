# MiMo 原始音频回归样本

`mimo-voice.wav` 是 2026-10-29 使用 App 已授权配置生成的真实 MiMo 测试音频，原文为“这是一段语音测试，检查浏览器能否正常播放。”，不含用户书籍内容或凭证。

格式：24 kHz、单声道、16-bit PCM WAV，时长约 5.76 秒。保留该文件以便不依赖远程服务也能覆盖真实媒体解码，而不只使用 mock 的 `Audio.play()`。

运行 `node desktop/speech-smoke.cjs` 对分发 App 验证普通阅读、单行阅读、暂停 / 继续、实际播放完成驱动翻页和 CSP。测试仅替换合成 HTTP 响应，使用真实 Electron 音频加载与解码。

设置 `DUOBOOK_REAL_SPEECH=1` 后运行同一脚本，会使用隔离桌面实例已有的私人初始语音配置请求真实服务。不要将配置或 Key 写入测试和日志。
