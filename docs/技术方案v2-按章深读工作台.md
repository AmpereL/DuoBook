# 逻辑阅读技术方案 v2：按章深读工作台

版本：2.16 · 同步日期：2026-10-30 · App 1.2.10

状态：以当前 App 实现为基准的技术说明。本文替代此前 v2 的目标设计描述；已实现能力与待实现事项分开记录。后续代码和交互变更应同步更新本文。

## 1. 产品定位与主流程

逻辑阅读以书籍原文为基础，提供章节工作台、章节脑图和阅读单元深读页。核心对象为书籍、章节、阅读单元版本、九段阅读笔记、原文批注。

```text
导入文件 → 确认目录 → 章节工作台 → 直接阅读本章原文
                           ↓ 用户点击“拆分本章”
                    语义规划 → 独立冷读 → 校验与发布
                           ↓
                   阅读单元标题 → 单元原文与九段笔记

章节工作台 ⇄ 逻辑地图：书籍 → 章节 → 最新版本的阅读单元
已拆分章节 → “重新拆分本章” → 新版本；历史版本及笔记保留
```

导入、刷新、进入章节及打开地图均不自动调用拆分模型。每次拆分只处理选定章，完成后不自动拆下一章。旧的观点、证据、因果关系地图不参与新流程；新逻辑地图只表达书籍、章节、阅读单元的归属关系。

## 2. 三个 skill 的内化范围

| skill | 当前内化能力 | 当前边界 |
|---|---|---|
| book-ingest | 源文件留档、格式解析、章节与段落入库、目录确认 | 仍是格式适配和规则识别；尚无完整的逐书结构判断、声明排除和全源覆盖报告 |
| chapter-split | 手动选章、完整章输入、语义标题与边界、独立冷读、连续段落切片、九段骨架、版本保存 | 不依赖运行时 Codex；没有独立 worker、断点恢复或人工复核候选页 |
| annotate | 单段精确选区、直接摘抄或附加笔记、后端子串校验、原文就地高亮与删除 | 跨段摘抄需分次保存；尚未实现笔记编辑、批注组与幂等键 |

App 不直接执行本机 skill 脚本，也不执行模型生成的 Python。提示词位于 `services/api/app/providers.py`，切片与保存由可信程序完成。技能是工作流依据，不能把技能文档中的所有能力视为 App 已实现。

### 3.1 书架与导入

2026-09-22 封面更新：书架及继续阅读卡片优先显示 EPUB 中声明的原版封面，支持 EPUB 3 `cover-image`、EPUB 2 `meta name="cover"` 和 guide 封面页中的图片引用。图片由 `GET /api/v1/books/{book}/cover` 提供，读取留档源文件，已有书籍无需重新导入。服务端按文件修改时间缓存结果，封面单资源上限 10 MB，仅返回识别到的 PNG/JPEG/GIF/WebP，不执行封面 HTML/SVG。前端完整显示图片，不拉伸裁切；缺失、格式不支持或加载失败自动回退现有图形封面。当前不联网匹配封面，TXT/PDF 使用图形回退。此变更已包含在 1.1.0 桌面安装包中。

导入后进入“确认目录”，可修改书名、作者和章节标题。主按钮为“完成导入，选择章节”。确认只更新结构，不生成地图数据或阅读单元。

书架封面、“打开工作台”和“打开书籍”统一经书籍入口恢复上次位置；继续阅读卡片优先展示最近实际阅读的书籍及章节 / 单元标题，没有记录时才回退示例书或其他可读书。全局搜索及显式目录链接保留用户指定的目标，不被其他章节的恢复记录重定向。

### 3.2 章节工作台

左侧为有序章节目录及“逻辑地图”入口；右侧展示当前章标题、状态、原文段数、章节导读和阅读单元列表，下方可直接阅读整章原文。即使尚未拆分，整章原文也支持选区摘抄和划线笔记。

1.2.2 起，章节切换的加载状态只替换右侧内容，左侧目录 DOM 保持挂载。目录按书籍保存当前标签页的滚动位置，刷新及从其他页面返回时恢复；小屏横向目录同样保持位置。未实现退出应用后的目录位置同步或跨设备恢复。

- 未拆分：显示“拆分本章”。
- 已拆分：显示“重新拆分本章”，无需先删除笔记。
- 处理中：显示当前任务消息与进度，暂不允许再次创建同章拆分。
- 模型请求期间页面显示随等待时间平滑前进的预估进度，最多到 92%；仅后端任务完成后显示 100%。预估值不代表模型实际完成比例。
- 失败：显示错误并允许重试；已有发布版本继续可读。
- 存在多个版本：可展开“历史拆分版本”，按生成时间打开旧单元。

默认选第一章，因此不存在必须手动选章才能启用按钮的空选中态。章节状态由最新任务及已发布单元共同决定，处理中/失败状态优先于已有单元的 ready 状态。

### 3.3 逻辑地图：脑图式导航

实现文件：`apps/web/src/pages/ChapterMapPage.tsx`，采用 React Flow。

```text
                         书籍
                          ↓
           章节一       章节二        章节三
             ↓          未拆分          ↓
       单元标题列表    [拆分本章]    单元标题列表
             ↓                         ↓
          单元原文                    单元原文
```

- 自上而下布局：书籍位于顶部，章节位于中间，单元位于下方。
- 章节按 `ordinal` 从左到右排列，单元按 `ordinal` 排列；每章按子单元数预留横向空间。
- 章节节点标题进入章节工作台。
- 已拆分章显示最新发布版本的单元标题，单元标题进入对应阅读页。
- 未拆分章显示“未拆分”和“拆分本章”；失败时展示原因并可再次点击。
- 提交后显示处理状态，并轮询章节列表；任务完成后自动增加单元节点。
- 地图仅展示当前版本；旧版本通过工作台的历史入口访问。
- 重拆入口在章节工作台，已拆分地图节点本身没有重拆按钮。

视口与 Mac 触摸板配置：

| 配置 | 当前值与效果 |
|---|---|
| `panOnScroll` | `true`，双指滑动平移画布 |
| `zoomOnScroll` | `false`，普通滚动不缩放 |
| `zoomOnPinch` | `true`，双指捏合缩放 |
| `nodesDraggable` / `nodesConnectable` | `false`，节点不能被用户改位或连线 |
| `fitViewOptions` | padding 0.15，初始缩放限制 0.85–1 |
| 手动缩放范围 | 0.08–1.8，保留控制按钮 |

默认不把大量章节强行缩到一屏全部可见，用户平移查看其他分支。85% 是初始适配下限，不是手动缩放下限。移动端也使用同一地图路由，尚无专用目录抽屉替代。

### 3.4 单元阅读页与九段笔记

左侧为所属章节及该版本的单元导航，中间纵向排列九段骨架。提供返回工作台、返回逻辑地图、上一单元和下一单元。旧单元导航只连接同一旧版本，避免跳到最新版本。

切换单元时保留同书目录元数据，右侧展示加载提示；旧原文、笔记编辑器及朗读组件在等待期间不显示。目录滚动位置按拆分版本保存到当前标签页会话，避免新旧版本互相覆盖。

| 序号 | 标题 | 初始化及编辑行为 |
|---|---|---|
| 一 | 原文 | 原文完整预填；不可编辑；页面从关联段落读取 |
| 二 | 字词注 | 空白，用户填写并保存 |
| 三 | 白话直译 | 空白，用户填写并保存 |
| 四 | 注家对照 | 空白，用户填写并保存 |
| 五 | 与前章/上一单元的连接 | 空白，用户填写并保存 |
| 六 | 三个问题 | 空白，用户填写并保存 |
| 七 | 生活关联 | 空白，用户填写并保存 |
| 八 | 你的理解/疑问 | 空白，用户填写并保存 |
| 九 | 回看批注 | 空白，用户填写并保存 |

拆分不会自动填充二至九。每节独立点击保存，尚无自动保存、编辑冲突检测或离页草稿保护。旧数据库中的四栏骨架尚未统一迁移为九栏。

九段第二节至第九节的非空正文视为「九段笔记」，与选区批注、段落笔记一并进入「阅读笔记」页。笔记页不直接编辑九段正文；点击条目回到对应单元阅读页继续改写。

### 3.5 语音阅读（App 1.2.0）

章节全文与单元原文共用 `SpeechReader`，默认使用本地系统语音。支持选择开始段落、音色、低沉/自然/明亮声调及 0.5–2 倍语速，提供暂停、继续与停止按钮，并高亮当前段。只朗读当前页面原文，不自动跨章节或单元跳转。

- 本地模式使用 Web Speech API，仅列出 `localService` 声音，不需要 Key；无可用声音时提示用户安装系统声音或切换 MiMo。本地声调映射到 pitch 0.75/1/1.25，具体效果取决于系统声音；更改语速会从当前片段重读。
- MiMo 使用 `mimo-v2.5-tts`，默认音色和中英文预置音色。目标原文置于 `assistant` 消息，声调指令置于 `user`；不发送不受支持的数值 pitch 参数。语速由 `HTMLAudioElement.playbackRate` 实时调整并保持音高。
- 1.2.1 起支持独立语音地址和 Key，设置页提供保存及测试入口。优先使用 `SPEECH_CONFIGURATION`，未配置时才沿用解析 `MODEL_CONFIGURATION.api_key`。普通 API 的 `sk-` Key 使用 `https://api.xiaomimimo.com/v1`，Token Plan Key 使用对应套餐地址。只将 Key 发送至受支持的 MiMo 官方主机，读取接口不回显 Key。
- 前端按最多 240 个 Unicode 字符切片，优先在句末断开，不改变数据库原文。后端以段落 ID 和 Unicode 起止偏移读取原文、校验所属用户及 800 字符上限，返回 WAV 音频。播放当前片段时最多预取下一片；失败不静默更换模型，用户可重试或手动选本地模式。
- 停止、切换模型/音色/声调或离页时取消播放及前端请求、释放 Blob URL，迟到响应不再播放。取消已提交的 HTTP 请求不保证终止上游正在进行的合成。
- 网页通过 `localStorage` 保存朗读偏好；桌面通过受来源校验的 IPC 保存 `speech-preference.json` 至既有用户目录，以跨随机端口重启恢复。音频只在内存中使用，不写入书籍或笔记。
- 网页独立语音连接保存到 `services/api/data/speech-defaults.json`（权限 0600，Git 忽略），自定义或隔离数据库使用其同目录 `.speech.json` 旁车文件；启动可通过 `DUOBOOK_TTS_BASE_URL`、`DUOBOOK_TTS_API_KEY`、`DUOBOOK_TTS_TIMEOUT` 覆盖。桌面用户保存的语音连接由 safeStorage 加密为 `speech.enc`，启动时优先读取，再读取私人包中的语音默认配置；原解析配置不变。

接入依据：[MiMo V2.5 语音合成](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5)、[首次调用 API](https://mimo.mi.com/docs/zh-CN/quick-start/summary/first-api-call)。2026-10-27 旧 Token Plan Key 返回 401；用户随后提供新的普通 API 语音 Key，已成功生成约 6.08 秒、24 kHz WAV。自动化用隔离的合成响应验证播放流程。

1.2.5 修复桌面实际播放：旧包 CSP 未指定 `media-src`，媒体继承 `default-src 'self'`，因此拦截播放器创建的 Blob 音频 URL；旧包实测触发 `media-src` 违规与 MediaError 4。桌面策略仅新增 `media-src 'self' blob:`，保留脚本、网络同源限制及本地 token 鉴权。MiMo 普通阅读失败后直接重试沿用失败片段索引；用户主动改选开始段落会重置错误状态，优先遵从选择。

回归新增 `desktop/speech-smoke.cjs` 与真实 MiMo WAV 样本，不 mock 媒体播放：验证完整桌面 CSP、真实解码、普通与单行朗读、暂停 / 继续、实际播放结束驱动翻页及收起。使用 `DUOBOOK_REAL_SPEECH=1` 同时验证真实服务；2026-10-29 已通过普通 / 单行真实合成到播放的完整链路，不只检查音频头或用 mock 的 `play()` 判定成功。

### 3.6 单行悬浮阅读（App 1.2.3）

章节全文和阅读单元的语音区域新增“单行阅读”。桌面打开独立无标题栏窗口并隐藏主窗口；网页进入中性背景页面，页面内阅读条可拖动。桌面常态实测 600 × 36 像素；宽度 320–1200、字号 12–20 可调，大字号允许适度增加行高，常态不出现第二行工具栏。语音和其他设置通过更多菜单按需展开。

- 实现：`CompactReaderPage.tsx`、`compactReading.ts`、`CompactReaderEntry.tsx` 和 `desktop/compact-reader.cjs`。桌面仅把左侧把手声明为原生拖动区域；网页通过指针捕获拖动，位置限制在可见范围。正文可选择和复制。
- 分页：Canvas 按实际字体和正文容器宽度测量，优先在标点处断开，每片不超过 240 个 Unicode 字符，数据库原文不改动。长句连续分屏，不通过永久省略正文实现单行。位置为书籍、章节 / 单元、段落 ID 及段内 Unicode 偏移；更改宽度、字号后按同一锚点重排。换行等空白在阅读条中显示为空格，语音读取原文。
- 进度（1.2.8 首版，1.2.9 默认升级为全书，见 3.9）：阅读条常驻 `56.78%` 形式的当前章 / 单元百分比；预计算 Unicode 字符总数和段落前缀偏移，按 `(段落前缀 + 当前片段 end) / 总字数 × 100` 保留两位小数，末行 100.00%。更多菜单与常驻百分比共用结果，原文收起时清除数字和提示、保留占位，避免触发正文重排和偏移回退。固定 58px 与等宽数字，Canvas 自动按剩余正文宽度重排；调宽 / 字号可能改变当前行末及百分比，恢复按已保存锚点重算。空原文 / 加载中为占位符，不伪造完成度，不新增数据库字段，也不表示全书进度或逐字播放时间。
- 操作：按钮、左右键、阅读条内滚轮 / 触摸板前后翻屏；惯性滚动累计阈值 45px、节流 350ms。输入框内不接管左右键与空格。更多菜单支持上下段、选章节和返回完整原文。末屏点击下一屏进入相邻单元 / 章节，全文末尾停止；跨章节遇到未拆分内容直接读章节原文，不调用解析模型。
- 语音：复用 MiMo / 本地语音及已有配置；当前行片段播放结束驱动下一行，不用固定计时。MiMo 最多预取下一片，等待期间保留原文并显示小型状态。播放中手动翻屏从新位置继续；暂停中翻屏保持暂停。空格键在菜单关闭时控制播放 / 暂停。默认当前章 / 单元结束即停，可开启连续朗读。首版仅片段级同步，未实现逐字时间戳。
- 播放互斥：同一窗口内播放器注册表及同源 BroadcastChannel 停止其他会话。主窗口切换到悬浮窗时停止原声音，新窗口不自动发声。更改模型、音色、声调停止；更改宽度、字号重排时暂停。停止、遮盖、离页释放音频与请求，迟到响应不播放。
- 遮盖：Esc 或菜单“收起”移除正文、位置数据属性与章节信息，显示“资料 · 点击恢复”，并停止音频 / 自动翻页。再次 Esc、聚焦、鼠标移回不恢复；点击恢复后保持停止。可选失焦自动收起，默认关闭。遮盖状态刷新 / 重开保持，输入法组词时不抢占 Esc。
- 持久化：网页 `localStorage`；桌面受来源与窗口身份校验的 IPC 写入 `compact-reader.json`，仅保存阅读锚点与偏好，不保存原文或 Key；`compact-window.json` 保存桌面位置，随机端口重启后恢复。位置按书籍与章节 / 单元隔离，最多保留 300 个条目。屏幕变化时约束窗口到当前可见工作区。
- 返回：关闭小窗或菜单“返回完整阅读”重新显示主窗口，SPA 导航到章节 / 单元的 `#paragraph-…` 并滚动到段落；不重新加载主窗口。网页返回同样带段落锚点。首次进入可从选区或正在朗读的段落开始，否则恢复此前位置。
- 边界：1.2.9 已支持单行选字摘抄 / 笔记；网页阅读条不能脱离浏览器。系统窗口置顶仅桌面可用，1.2.4 网页提供页面内置顶。收起只改变显示及声音行为，不承诺隐藏系统进程或网络记录。断点恢复至当前片段，不承诺字级续播。主阅读页常规朗读仍不自动跨章节。

操作说明见 [单行阅读使用说明](单行阅读使用说明.md)，设计与实际范围见 [单行悬浮阅读方案](产品方案-单行悬浮阅读.md)。

1.2.4 补充：常驻图钉按钮和设置内的开关同步置顶状态；桌面调用 `setAlwaysOnTop`，网页只切换页面内层级，并明确无法置于其他应用之上。增加 Page Up / Page Down 翻行快捷键，与左右键并存；设置顶部和按钮提示公开快捷键，输入控件内不接管。

设置中的 `backgroundTransparency` 为 0–100，缺省 0，网页与桌面均校验并持久保存。桌面小窗创建时使用透明窗口、透明原生背景并关闭原生阴影；HTML 根节点和原生阅读舞台透明，阅读条背景 / 边框 / 网页阴影按百分比调整 alpha。文字与按钮不使用整体 opacity 淡化，设置面板仍保持实色。网页仍在原页面背景上合成透明阅读条，无法透出浏览器外窗口。透明度变化不重新分页或停止语音。macOS 13 与跨全屏空间、其他系统窗口管理器的合成效果仍需真机验证。

### 3.7 持久阅读位置（App 1.2.6）

新增 SQLite `reading_positions`，按用户及书籍保存一条最新位置，不复用旧地图的 `reading_states`。字段包括章节、可选历史阅读单元、原文段落、Unicode 字符偏移、九段区域编号、区域内相对比例、客户端捕获时间和服务端保存时间。初始化以 `CREATE TABLE IF NOT EXISTS` 增量增加表，不清空原库。章节删除级联移除位置，单元或段落删除清空相应锚点并回退章节；重新拆分保留的历史单元仍可恢复。

- 接口：`GET /api/v1/books/{book}/reading-position` 返回有效位置和服务端生成的安全恢复路径；`PUT` 校验章节属于当前书籍版本、单元属于章节、段落属于单元 / 章节及 Unicode 偏移范围。只接受较新的捕获时间，旧窗口迟到的保存不会覆盖新位置。
- 普通阅读：`useReadingPosition` 在目录和正文就绪后恢复，监听滚动、朗读段落和笔记区域聚焦。原文按视口阅读线选择段落并保存段内比例；单元可保存九段笔记区域。初始恢复不自动播放语音。显式原文 hash 链接优先；页面离开和 Suspense 隐藏不把记录覆盖成顶部。
- 单行：每次翻行或语音推进均同步当前段落及精确字符偏移到同一数据库；仍保留独立的单行偏好和旧位置兼容。进入单行前、返回完整阅读前会提交待保存位置。书架打开回到完整阅读页并定位，进入单行可继续该行，不自动恢复声音。
- 保存：前端按书籍合并最新快照、300ms 合并提交，并在离页时补交。服务端同步更新 `books.last_read_at`；书架收到保存通知后更新继续阅读卡片。正常退出桌面时先请求各阅读窗口提交，再等待主进程保存请求完成，最后停止后端；设置超时以免服务异常导致无法退出。隐藏主窗口不会重采样旧内容覆盖小窗位置。
- 持久化范围：网页与桌面均保存至各自运行实例的 SQLite，支持浏览器新会话和 App 重启；不同数据库之间不做跨设备同步。普通模式为段落 / 区域内相对位置，单行为字符片段锚点，不承诺普通模式逐字音频续播或断电前最后一帧保存。

使用说明见 [阅读位置记忆](阅读位置记忆使用说明.md)。

### 3.8 单行全局隐藏 / 显示（App 1.2.7）

桌面默认注册 `CommandOrControl+Shift+H`，Mac 显示为 ⌘⇧H，使用 Electron `globalShortcut`，不依赖网页焦点。仅在单行小窗存在时注册，关闭小窗 / 退出时释放。配置独立存为既有用户目录内的 `compact-shortcut.json`，避免普通单行偏好保存覆盖系统注册状态。

- `desktop/compact-shortcut.cjs` 管理配置校验、注册、改键、禁用与释放。更换组合键先注册新键，成功保存后再释放旧键；失败保留旧键和配置。启动冲突返回明确状态，可在设置中更换或重新保存。
- `desktop/compact-reader.cjs` 的全局回调执行原生 `hide()` / `showInactive()`，显示时 `moveTop()` 但不抢焦点；隐藏不调用关闭窗口逻辑，因此不显示主阅读页。相邻切换回调限流 250ms。点击 Dock 可找回隐藏的小窗。
- 隐藏先在主进程静音，再通过受来源校验的 IPC 通知根 App 停止全部播放器、取消请求、关闭设置并收起原文；显示是手动恢复原文动作，继续保持停止。显示时确认当前轮次已处理后才解除媒体静音，旧确认不解除后续隐藏状态。隐藏标记同时阻止新单元延迟自动播放。
- 设置可录入至少两个修饰键加字母 / 数字 / F1–F24，保存并显示注册状态，支持关闭。录键时若小窗仍聚焦，不执行该组合键的隐藏动作；失去焦点后全局切换仍有效。启用状态及组合键在 App 重启后恢复。
- 网页仅说明能力边界，不提供虚假的系统注册；原翻页 / 播放 / Esc 仍为页面焦点内快捷键。恢复小窗、阅读位置保存、透明度、置顶及模型配置沿用现有实现。

### 3.9 单行批注与全书进度（App 1.2.9）

- `useCompactAnnotation.tsx` 提取当前行 DOM Range；前缀长度按 Unicode 码点计算，再加上 `chunk.start`，从不可变段落切片获取真实 quote。界面空白压为等长空格，保存仍为原文。`OriginalTextHighlight.tsx` 供普通和单行阅读共用，支持片段范围与重叠高亮。
- 选字暂停语音，临时展开 280px 批注区（默认桌面窗口 600 × 316），保存 / 关闭收回 600 × 36；选字交互标记阻止末行迟到完成事件跨章，明确播放后才解除；语音保持暂停，输入框内不触发翻行。失败保留草稿，点击外部关闭；翻行 / 菜单 / Esc / 全局隐藏清除选区和草稿，已发出的保存不能撤回。
- 沿用 POST `/annotations`，不新增笔记表；更新源查询、笔记和阅读单元缓存。原生主窗口收到返回事件时刷新章节 / 单元 / 笔记，再定位原文，避免隐藏窗口显示旧批注。
- GET 章节与 GET 阅读单元的响应增加可选 `reading_progress`：`total_characters`、`paragraphs: [{paragraph_id, start_character, character_count}]`。服务端只统计当前 book version 的原文，按章节 ordinal 与段落 ordinal 排序；仅返回当前源的偏移，不传输其他章节正文。重复拆分及历史单元不重复统计。
- 全书百分比为 `(段落全书起点 + chunk.end) / total_characters × 100`，固定两位小数。跨章 / 单元延续，全文最后一行 100%；回看会降低。零字数 / 缺元数据为占位符，不能回退伪装成全书数值。
- `progressScope: book | source` 默认 `book`，设置切换当前常驻范围，菜单同时显示全书与局部进度；网页与原生偏好规范化均支持，旧设置自动默认全书。进度仍固定 58px 占位，收起清除内容而不改正文宽度。

## 4. 导入解析及此次 TXT 修复

实现文件：`services/api/app/parsers.py`。当前开放 EPUB、TXT、PDF；文件上限 50 MB，EPUB 解压上限 150 MB，解析文本上限 300,000 字符。Markdown、MOBI、AZW 等尚未接入。

### 4.1 TXT

UTF-8 解码，按源文本出现顺序识别独立章标题行，再按空行切段。

此次修复：

1. 章标题使用整行匹配。章号后可有空白分隔的短标题，排除带句末标点的正文式长行。
2. 仅有“第1章”时，检查后面第一个非空行；若是独立、最多 60 字且无指定句末标点的文本块，将其拼入章节标题。
3. 被识别为下一行标题的文本仍保留在原文中，避免误判时丢失内容。
4. “第14章所描述的……”不再作为章节边界，留在原所属章正文。
5. 顺序遵循源文件，不对提及的章节数字重新排序。

已修复本地《投资最重要的事》：错误识别的 22 章恢复为 21 章，补齐标题；误切出的第14章引用归回第16章。修复前完成数据库备份，保留原有段落 ID，补回被旧解析当作标题遗漏的正文引用句，并校验数据库段落顺序与重新解析结果一致。

这是已观察 TXT 结构的规则修复，不是通用逐书理解系统。重复目录、无空白的章号与标题、其他编号风格仍需补充识别；未实现完整章节编号连续性校验。首章前文本在当前 TXT 分章路径仍未纳入章节，不能宣称全源覆盖。

### 4.2 EPUB 与 PDF

- EPUB 按 OPF spine 文档顺序提取正文；有 EPUB 2 NCX 或 EPUB 3 nav 目录时，解析其资源路径及锚点，在同一 spine 文档中也可切成多章。无可用目录时仍按 spine 文档与 h1/h2/h3 回退。程序按原文段落顺序验证切片完整覆盖。当前以段落为最小边界，锚点落在段落内部时尚未做到字符级切分。
- 2026-09-23 已根据留档 EPUB 修复《一转念》：原 2 个 spine 文件内实际有 44 个 NCX 目录条目；现为 44 个有序目录单元，984 段正文顺序及原段落 ID 保持不变。修复前备份 SQLite 数据库；原文件与已有原文不改写。目录中也包含自序、三辑标题及英文原版等条目，当前按出版物目录保留，未静默排除。
- PDF 优先按书签范围解析；没有书签时按最多 12 页的批次形成“节”。扫描件检测主要依据总可提取字数，低文字页记录问题，尚无严格逐页覆盖保证。
- 源文件留档，数据库保存提取后的文本和位置。当前规范化会调整空白，所谓原文不可编辑指入库后段落，不代表与电子书排版逐字节一致。

## 5. 章节拆分工作流与契约

核心实现：`generation.py:split_chapter`、`reading_units.py`、`providers.py`。

```text
核对书籍与章节归属 → 读取该章全部 ready 段落
→ 模型规划标题、起始段落及导读
→ 段落连续切片校验
→ 独立冷读（独立请求，不传规划理由）
→ 未通过时将问题交回规划者修订，再冷读一次
→ 通过后短事务保存新单元版本、九段骨架
→ 任务完成，页面读取最新发布版本
```

模型计划主要字段：

```json
{
  "intro": "章节导读",
  "units": [{
    "title": "阅读单元标题",
    "start_paragraph_id": "p_1",
    "purpose": "这段在做什么",
    "independence_reason": "可独立阅读的依据",
    "density_note": "信息密度说明"
  }]
}
```

模型不输出重写的正文。程序从起始段落到下一个单元起始段落前切片，末单元延伸至章末。校验首段、锚点有效性、唯一性、顺序及全章段落恰好覆盖。保存章节正文哈希与模型路由。

远程模型的规划和冷读响应须为 JSON 对象。程序先修复尾随逗号与字符串内换行；仍无效时最多重试两次，保持原文输入不变，要求完整标准 JSON，并提高输出上限、降低随机性。三次均失败时保留旧发布版本并将错误显示在任务中，不猜测缺失结构或跳过冷读。

当前模型适配器会过滤部分无效计划项并按原文顺序整理后交给切片层；不能宣称模型原始乱序一律被拒绝。尚无 `source_revision_id`、段首字符串复核、完整计划审计表或发布后逐字符回装复核。

冷读检查完整性、首尾悬空、主题混合、密度和相邻合并。最多两轮，仍未通过则任务失败，不发布新版本；没有 `needs_review` 人工候选页。未实现长章 token 预算预检和跨窗口拆分。

本地模式会将整章保留为一个单元，标记 `local_unreviewed`，跳过模型冷读。配置远程默认模型后，新任务使用远程模型；本地模式不代表完成语义质量审核。

## 6. 重新拆分与历史保护

重新拆分使用同一个章节 `split-runs` 接口。已有笔记不再阻止重新拆分。

- 每次成功创建独立 `unit_sets` 及新单元、九段骨架。
- 按发布时间选择最新成功版本，不删除旧版本。
- 新任务执行或失败时，旧单元仍可进入。
- 工作台历史入口保留旧笔记；不自动复制、迁移或合并到新单元。
- 批注锚定原文段落，同一段落出现在新旧单元中时，两者均可查询到相关批注。
- 其他章节版本不随本章重拆而重建。
- 同章已有 queued/running 任务时返回该任务；此为查询式去重，尚无数据库级并发唯一约束。

## 7. 批注实现

用户在章节工作台的整章原文或阅读单元原文中，选择同一个自然段内的文字后，浮动工具条提供“只做摘抄”和“添加笔记”。前者立即保存原文引用，后者打开小型编辑器，填写内容后保存。两页共用选区和展示组件。请求包含 `paragraph_id`、`start_offset`、`end_offset`、`quote`，笔记正文 `body` 可为空；空正文表示仅摘抄。

前端从真实 DOM Range 计算选区位置，把 JavaScript UTF-16 偏移转换为 Unicode 字符偏移，再核对选区与原文精确一致；不会因重复句误锚到首次出现处。后端再次校验段落、范围和精确子串，事务写入 `annotations` 和 `annotation_anchors`；不修改段落正文。保存后在原文位置高亮，页面下方展示摘抄与笔记，允许删除。

跨段选区不支持，用户需按自然段分别保存。未拆分时保存的锚点绑定原文段落，拆分后会在所属阅读单元显示。尚未实现已有笔记编辑、批注组和幂等键。摘抄与划线笔记可在章节工作台、单元页或阅读笔记页删除。

选区操作框点击外部或按 Esc 会收起，同时清除未保存草稿；框内点击不关闭。

### 7.1 统一阅读笔记

「阅读笔记」汇总三类用户内容，并保留各自来源链接：

| 类型 | 来源表 | 判定 | 回跳目标 |
|---|---|---|---|
| 九段笔记 | `reading_unit_sections` | `ordinal` 2–9 且 `body` 非空 | 对应阅读单元页 |
| 摘抄与划线笔记 | `annotations` / `annotation_anchors` | 空 `body` 为仅摘抄，非空为划线笔记；按锚点段落解析单元与章节 | 所属阅读单元；无单元时回章节工作台 |
| 段落笔记 | `notes` | 旧段落级笔记，继续兼容 | 所属阅读单元；无单元时回章节工作台 |

每条笔记统一携带 `kind`、`book_id`、`book_title`、`chapter_id`、`chapter_title`、`reading_unit_id`、`reading_unit_title`、`section_ordinal` / `section_title`、`paragraph_id` / `paragraph_text`、`quote`、`body` 及可回跳路径。列表默认混合按更新时间倒序；九段笔记暂无独立时间戳时按章节/单元/节次排序垫后。支持 `kind` 筛选与按书过滤。

删除行为：段落笔记与选区批注可删除；九段笔记不在列表删除，只提供「打开单元」在骨架中继续编辑。导出 JSON 同步包含三类内容。

笔记总览的导出入口下载所有书籍的全部笔记，与当前页面的类型筛选无关。Markdown 包含来源、原文引用、笔记正文及应用内路径；JSON 保留笔记字段供备份或后续处理。书架中原有按书 JSON 导出保持不变。

## 8. 服务架构与数据

前端：React、TypeScript、Vite、React Query、React Router、React Flow。
后端：FastAPI、SQLite、HTTP 模型适配器；运行时本地数据库与源文件仓库。

```text
书架 / 工作台 / 脑图 / 阅读页
             ↓ HTTP
FastAPI main.py → SQLite db.py
             ↓ BackgroundTasks
jobs.py → generation.split_chapter
             ↓
providers.py：规划 / 冷读
             ↓
reading_units.py：连续切片与事务发布
```

| 表 | 当前职责 |
|---|---|
| books / book_versions | 书籍元数据、源文件及哈希、当前版本 |
| chapters / paragraphs | 章序、标题、提取原文、段落顺序及位置 |
| unit_sets | 章节拆分版本、正文哈希、模型路由、导读、发布时间 |
| reading_units / reading_unit_paragraphs | 单元标题、审核状态、连续段落关联 |
| reading_unit_sections | 九段骨架及用户编辑内容，第一节存原文副本；2–9 节非空正文即九段笔记 |
| annotations / annotation_anchors | 批注及精确段落引用 |
| jobs / job_chapters | 任务状态、进度、错误与所属章节 |
| notes / reading_states / read_paragraphs | 段落笔记与阅读记录；笔记列表与九段笔记、批注统一汇总 |
| reading_positions | 每本书的最新阅读位置与恢复路径，独立于旧地图状态，支持章节 / 历史单元 / 原文 / 九段区域 |

旧 `nodes`、`relations`、`map_versions` 及旧地图 API/代码仍保留，未做物理删除或全面迁移。新脑图读取章节及单元列表，不使用旧地图投影。

任务在 FastAPI BackgroundTasks 中执行，SQLite 保存状态，但没有独立 worker、租约、检查点、取消与重启自动恢复。进度是粗粒度阶段值，不代表 token 完成比例；不同章没有统一的每书串行队列。

## 10. 当前 API

以下路径均以 `/api/v1` 为前缀。

| 方法与路径 | 功能 |
|---|---|
| POST `/books/upload` | 上传、解析、留档；不拆阅读单元 |
| GET / PATCH `/books/{book}/structure` | 读取、确认目录与书籍信息 |
| GET `/books/{book}/chapters` | 有序章节、状态、任务及最新单元列表；供脑图使用 |
| GET `/books/{book}/chapters/{chapter}` | 章节全文、当前版本、单元、历史版本及其单元 |
| POST `/books/{book}/chapters/{chapter}/split-runs` | 首次或重新拆分当前章 |
| POST `/books/{book}/generation-runs` | 返回 422 `CHAPTER_REQUIRED`，不执行全书拆分 |
| GET `/reading-units/{unit}` | 指定单元及同版本导航、原文、九段骨架和批注 |
| PATCH `/reading-units/{unit}/sections/{ordinal}` | 保存第 2–9 节；第 1 节不可编辑；无修订号 |
| POST `/annotations` | 创建单段精确批注 |
| DELETE `/annotations/{annotation}` | 删除批注及其锚点 |
| GET `/notes` | 统一阅读笔记列表；支持 `book_id`、`kind` 筛选 |
| GET `/notes/export?format=markdown\|json` | 下载全部笔记；默认 Markdown |
| GET `/jobs/{job}` | 当前状态、消息和进度 |
| POST `/jobs/{job}/retry` | 重试原任务所属章 |
| GET / PUT `/settings/model` | 读取脱敏配置、更新进程配置 |
| POST `/settings/model/test` | 测试连接与计划格式 |
| GET / PUT `/speech/config` | 读取脱敏语音配置 / 保存独立语音连接；不返回 Key |
| POST `/speech/test` | 用输入的或现存 Key 合成简短语音，验证 WAV；不覆盖已有配置 |
| POST `/speech/synthesize` | 以段落及起止偏移合成原文，返回 WAV；失败返回脱敏错误 |
| GET `/books/{book}/export` | 九段笔记、批注、段落笔记与阅读状态 JSON 导出 |

尚无 import-report、任务 cancel、annotations PATCH 或 Markdown ZIP 导出接口。当前为本地示例用户模式，不宣称具备完整多用户鉴权。

## 13. macOS 桌面封装

桌面入口为 `desktop/main.cjs`，使用 Electron + electron-builder；Python 后端由 PyInstaller onedir 打包，包含解释器与依赖。FastAPI 同源提供 Vite 生产静态文件及 API，监听随机 localhost 端口，通过每次启动的随机 token 校验请求。Electron 启动后等待健康检查，再创建禁用 Node 集成、启用上下文隔离和沙箱的窗口；退出时终止后端。

SQLite 和上传文件放在 Electron userData 目录，默认 `~/Library/Application Support/DuoBook/`（为兼容改名前的数据保持不变），不写入应用包。分发包不包含开发数据库或用户书籍。现有数据库初始化机制保留，尚未实现正式数据库版本迁移体系和任务重启恢复。

1.2.10 起默认构建 ARM64 无 Key 公开版。`npm run package:mac` 强制公开模式，分别使用 `build/desktop/public` 与 `release/public`；仅 `npm run package:mac:private` 明确复制本机私人初始配置，使用独立 private 目录。`desktop/electron-builder.cjs` 按模式选择资源，公开版不会携带任何私人配置文件。模式 / 版本清单与包内配置、已知 Key、用户数据扫描在归档前校验，失败停止交付。

公开版首次启动使用无 Key 的本地阅读模式；已有用户的书籍、笔记和 `model.enc` / `speech.enc` 在原目录保留。桌面后端不继承构建 shell 的语音凭据，用户后续填写的配置仍通过 safeStorage 加密保存并优先恢复。未配置自动更新或 Intel 构建。发布过程见 [公开分发与 Release 流程](公开分发与Release流程.md)。

本机无 Developer ID 证书，当前配置仅 ad-hoc 签名，Apple 公证未完成。可复现构建命令为 `npm run package:mac`；安装与校验见 [公开分发说明](../desktop/公开分发说明.md)，私人模式说明独立保留。

### 应用图标

四款图标资源位于 `apps/web/public/icons/`，用户可在设置页选择，初始默认第 2 款。网页端将选择保存在浏览器 `localStorage`，立即更新标题栏品牌图和 favicon。桌面版通过 preload IPC 将选择保存在 `~/Library/Application Support/DuoBook/icon-preference.json`，立即更新 macOS Dock 图标；重启后恢复。安装包及 Finder 中的静态 `.icns` 图标使用第 2 款，运行时选择不会改变应用包文件图标。
