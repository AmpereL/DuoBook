# 单行悬浮阅读产品方案 v2

更新时间：2026-10-30。状态：已在 App 1.2.9 实现，以下范围与当前代码一致。验证细节见技术方案和修复记录。

本方案替代此前“工作笔记 / 文档审阅”的整页外观。核心要求：窗口只有一行、可拖动，兼容现有语音阅读、翻页和阅读位置。

## 1. 窗口与布局

桌面版使用独立无标题栏小窗；网页版提供页面内拖动阅读条，不能脱离浏览器成为桌面小窗。

默认约 600 × 36 像素，宽度可调整；较大字号允许整条高度适度增加，但正文始终只有一行。

```text
⠿  人的判断常常受到所处环境的影响。    56.78%  ‹  ▶  ›  ···
```

- 左侧把手拖动，正文允许选中与复制，选字不拖动窗口。
- 正文按标点和可用宽度分页；长句连续分屏，不用省略号永久截掉内容，不用跑马灯。
- 右侧为上一屏、播放 / 暂停、下一屏、更多。翻页与播放按钮在悬停或键盘聚焦时显示，更多按钮常驻；预留按钮宽度，出现时不挤动正文。
- 默认全书百分比常驻右侧，可切换当前章 / 单元，固定两位小数、等宽数字，不随位数挤动正文；按当前行末累计原文字数计算，末行 100.00%，翻行和语音推进同步更新，收起正文时一并隐藏。表示原文位置，不是累计读完比例或音频时长进度。
- 书名、封面、大幅语音面板不常驻；更多菜单按需查看详细屏数、选择章节、调整设置或返回完整阅读。
- 记住窗口位置、宽度及字号；置顶可选，默认关闭。显示器变化后窗口保持在可见区域。
- 右侧常驻图钉按钮，设置内同步提供置顶开关。桌面为系统窗口置顶，网页仅页面内置顶，并显示范围说明。
- 背景透明度可在设置中调节 0–100%，0% 不透明、100% 背景全透明；文字与按钮保持清晰，设置面板保留实色。透明度会保存，旧偏好默认 0%。

## 2. 翻页与位置

“一页”指当前窗口容纳的一行原文。

| 操作 | 行为 |
|---|---|
| 上一屏 / 下一屏 | 切换相邻原文片段，支持按钮、左右方向键和 Page Up / Page Down，设置内显示快捷键提示 |
| 滚轮 / 触摸板 | 指针位于阅读条内时翻页，累计位移并节流，避免惯性滑动连跳多屏 |
| 空格 | 开始、暂停或继续朗读；输入框内不截获 |
| 更多 → 上一段 / 下一段 | 跳转到相邻原文段落开头 |
| 更多 → 选择章节 | 按需打开选择面板，选好回到单行阅读 |
| 更多 → 返回完整阅读 | 打开对应章节 / 单元并定位当前原文 |

手动读到章节 / 单元末尾后停在末屏，轻量提示已读完；再次点击下一屏再进入下一章节 / 单元。全文结束停止，不循环回开头。

位置记录为“书籍 + 章节 / 单元 + 原文段落 ID + 段内字符偏移”，不把屏数作为固定锚点。宽度和字号变化后重新分页，定位同一原文范围。

1.2.6 起，单行位置同时写入 SQLite，与普通章节、单元及九段区域共用每本书的最新阅读记录。书架打开恢复完整原文位置，进入单行可继续该行；正常退出会补交保存，不自动恢复声音。不同数据库不做跨设备同步。

从选中段落、上次单行阅读位置或章节开头进入。支持未拆分章节及已拆分阅读单元，进入时不触发模型解析。返回主窗口保留现有笔记与目录状态。

## 3. 语音阅读

复用现有小米 MiMo、本地系统语音、独立语音 API 配置与用户偏好，不新增 Key 配置入口。语速、声调、音色、模型在更多菜单的设置中调整，关闭设置恢复单行窗口；沿用各引擎实际支持的能力。

### 播放与自动翻页

1. 用户点击播放，从当前原文片段开始。首版以单行可显示的短句 / 片段作为播放与显示同步粒度。
2. 当前片段播放结束，显示下一片段并继续朗读；翻页由播放完成驱动，不按固定秒数估计。
3. MiMo 预取并缓存下一片段。等待合成时同一行显示小型加载图标并保留文字，不新增第二行；不承诺首次合成无等待。
4. 暂停时文字与阅读位置停住，继续时沿用引擎实际支持的断点；停止或重新进入后，从当前片段开头开始。首版不承诺无时间戳音频的逐字同步。
5. 默认读完当前章节 / 单元即停止。可开启“连续朗读下一章节 / 单元”，默认关闭，开启后按顺序继续，全文结束停止。

### 手动操作时的声音行为

| 操作 | 声音行为 |
|---|---|
| 播放中上一屏 / 下一屏、跳段、选章节 | 停止旧片段与队列，从新位置继续播放 |
| 暂停中翻页 | 保持暂停，更新文字与待播位置 |
| 更换模型、音色或声调 | 停止并清理待播队列，保留位置，用户重新点击播放 |
| 调整语速 | 沿用现有播放引擎支持的调整方式 |
| 改宽度或字号导致重新分页 | 暂停，保留原文锚点并重建片段，用户再次播放 |
| 切换主窗口与悬浮窗口 | 停止旧窗口播放，转移位置；新界面不自动发声 |
| 合成或播放失败 | 暂停并保留位置，同一行显示简短状态；菜单可重试或切换本地语音 |

主窗口与悬浮窗口共用一个播放会话，避免双重播放。旧请求迟到后不得覆盖新位置或继续发声；不做无限自动重试。

## 4. 快速遮盖与恢复

桌面新增系统级 ⌘⇧H 隐藏 / 显示整个单行小窗，失焦也生效。隐藏停止声音且不显示主窗口，再按显示原文、保留位置、保持静音且不抢焦点；设置中可改键 / 关闭，冲突保留原配置，重启记住选择。仅在小窗打开期间注册；关闭小窗后不自动打开书籍，Dock 可找回隐藏的小窗。网页不提供系统级全局键。

- 按 Esc 或点击更多 → 收起，立即隐藏原文，整条仅显示中性的“资料”，窗口仍是一行。
- 同时停止声音、预取和自动翻页，取消前端合成请求。上游已接收的合成不保证取消成功；迟到结果不得播放。
- 再按 Esc、鼠标移回、重新聚焦都不恢复原文；点击“资料”手动恢复，保留位置并保持暂停。
- 失焦自动遮盖可选，默认关闭。关闭小窗停止声音，重开不自动播放；若此前处于遮盖状态，重开先遮盖，避免闪现原文。
- 翻页 / 播放 / Esc 仅在阅读条获得焦点时生效；桌面全局隐藏 / 显示组合键不受焦点限制。输入法正在组词时 Esc 优先取消组词，菜单入口始终可用。

## 5. 笔记与设置边界

单行选中文字可直接摘抄或写笔记，临时展开面板，保存 / 关闭后回到一行。原文锚点与笔记在完整阅读和笔记列表同步；笔记汇总管理、书架、逻辑地图、模型配置在主窗口完成。

更多菜单与设置可以按需展开；关闭后回到单行。阅读时不常驻第二排工具栏。

## 6. 实现约束

- 桌面主进程管理独立窗口尺寸、位置、置顶和生命周期，沿用现有 App 标识与数据目录。窗口间不传递明文 API Key。
- 统一阅读会话管理原文锚点、播放状态及取消标识。翻页、遮盖、重试后忽略旧请求结果。
- 音频缓存与原文范围、模型、音色、声调绑定；切换配置后不复用旧音频，取消后释放资源。
- 阅读位置按书籍及章节 / 单元隔离，适度节流持久化，退出时补写最终位置。

## 1.2.9 增量功能

单行选字暂停语音，展开摘抄 / 笔记面板；保存或关闭恢复一行，使用精确原文段落和字符锚点，与普通阅读 / 笔记列表共用。失败可重试，收起清除未保存草稿。默认全书百分比，可切换章 / 单元进度，范围选择重启保留；跨章 / 单元和历史拆分按原文字数计算，不重复累计。百分比代表当前位置，回看时下降。
