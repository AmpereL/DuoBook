# 阅读位置记忆

适用版本：逻辑阅读 1.2.6。

阅读位置自动保存，无需点击书签或保存按钮。

- 在书架点击书籍封面、“打开书籍”或“打开工作台”，自动回到该书上次阅读的章节 / 阅读单元，并定位原文段落。
- 长段落会记住段内相对位置；改变窗口宽度后按新的排版恢复。阅读单元还能记住正在查看 / 编辑的九段笔记区域。
- 单行模式保存当前原文行的字符偏移。回到书架后再次打开，会在完整阅读页定位对应原文；再次进入单行可继续，语音需要手动开始。
- “继续阅读”卡片优先展示最近实际阅读的书及章节 / 单元名称。
- 直接点击目录、地图或笔记里的原文链接时，优先打开指定位置；不会被其他章节的旧记录强行跳走。
- 刷新、关闭浏览器后重新打开，以及桌面 App 正常退出后重启，均可恢复。旧版未记录过的位置无法追溯，升级后开始自动记录。

每本书各自记忆。重新拆分章节后，已发布旧单元仍然保留时可继续原版本；如果目标单元已移除，则回退所属章节。没有有效记录时进入第一章。

位置保存在当前运行实例的 SQLite 数据库，桌面数据目录仍为 `~/Library/Application Support/DuoBook/`，不上传云端。不同电脑、桌面与独立网页数据库不会自动同步。正常退出会补交位置；强制结束进程、断电或保存失败时，以最后成功保存的位置为准。
