# 单行悬浮阅读使用说明

适用版本：逻辑阅读 1.2.9。

## 打开

打开任意章节或阅读单元，在原文上方“语音阅读”区域点击“单行阅读”。无需先拆分章节。

桌面版打开约 600 × 36 像素的独立小窗，主窗口暂时隐藏。网页版在页面内显示可拖动阅读条，无法拖到浏览器外。

## 阅读与拖动

- 拖动最左侧六点把手移动窗口；文字区域用于选择和复制。
- 鼠标移入阅读条显示上一行、播放和下一行按钮。
- 左方向键或 Page Up 上一行，右方向键或 Page Down 下一行；Mac 紧凑键盘可用 Fn + ↑ / Fn + ↓。窗口内滚轮 / 触摸板也可翻页，快速滑动会节流。
- 每行是按当前宽度排好的原文片段，长句接续到下一行。末屏再点下一行进入下一章 / 单元。
- 阅读条右侧默认常驻两位小数的**全书进度**（例如 `56.78%`），按当前行末在整本书中的累计原文字数计算。跨章、跨单元仍使用同一分母，全书最后一行显示 `100.00%`。
- “…”→“进度显示”可切换为本章 / 本单元进度，选择会记住。菜单同时展示全书和当前范围的百分比。重新拆分的历史单元按原文位置计算，不重复计入字数；数据未就绪时显示“—”。
- 百分比表示当前所在的原文位置，回看前文会降低；不是累计完成的阅读量，也不是音频播放时间。
- 手动翻行、段落跳转和语音自动翻行均更新进度；调整宽度 / 字号按同一原文锚点重排，当前行末变化时百分比可能略变。收起时一并隐藏进度，恢复或重启按保存位置重新计算。
- 点击右侧“…”可查看百分比、屏数与段落、切换章节、上下段、调整字号及宽度；关闭设置后恢复单行。

## 单行划线、摘抄与笔记

选中当前行内的文字，会暂停朗读并展开“摘抄与笔记”面板。可以选择“只做摘抄”，或点击“添加笔记”填写想法再保存。保存后收回面板，恢复单行高度，不自动开始朗读。

- 划线保存到原有 SQLite 笔记系统，单行与完整阅读使用同一处段落 / 字符锚点；在单行中也能看到已有划线。
- 回到完整阅读或“阅读笔记”可查看刚保存的内容，也可随其他笔记导出。未拆分章节与已拆分单元都支持。
- 当前显示的空格可能来自原文制表符或换行，保存时使用精确原文；支持 emoji 和段内后续行的偏移。
- 保存失败会保留选区与草稿，可重试。点击面板外或关闭按钮会丢弃未保存草稿；翻行、切章节、打开设置也会关闭面板。
- Esc、失焦收起和全局隐藏会清除选区及未保存草稿，保持停止。重新显示不恢复草稿。保存请求已经提交时，关闭面板不会撤回已提交的保存。
- 当前以单行内选区为范围，跨多行内容需分别保存。

## 置顶与背景透明度

右侧图钉按钮可以开关置顶，“…”内也提供相同的开关。桌面版可让阅读窗口置于其他普通应用窗口上方；网页版是“页面内置顶”，不能跨出浏览器置顶。

“…”→“背景透明度”提供 0–100% 滑块：0% 为不透明，100% 为背景全透明，文字和按钮保持清晰，设置面板保持实色方便操作。桌面版可以透出下方桌面或窗口，网页版透出当前页面背景。置顶和透明度会保存，刷新或重启后恢复；旧版偏好默认 0% 不透明。

翻页和播放快捷键提示显示在设置顶部，这些按键需要阅读窗口获得焦点。调整输入框、下拉框或滑块时，方向键与 Page Up/Down 优先操作输入控件。

## 全局隐藏与显示（桌面版）

默认 **⌘ + Shift + H** 隐藏 / 显示单行小窗。App 在后台、其他应用获得焦点时也能使用；显示小窗不抢走当前应用的键盘焦点。

- 隐藏会真正隐藏小窗，停止系统 / MiMo 朗读、预取和自动翻页，保留阅读位置，主阅读窗口不会随之弹出。
- 再按一次显示小窗并恢复原文，声音保持停止，需要点击播放。这是用户手动显示动作；普通聚焦和鼠标移回仍不会自动恢复正文。
- “…”→“全局快捷键设置”中可修改或关闭。点击输入框，按下至少两个修饰键加一个字母、数字或 F1–F24，再点击“保存全局快捷键”；设置会保留到下次启动。
- 组合键被占用时会提示冲突，原来可用的组合键保持生效，不会被失败的修改覆盖。可换组合键重试。
- 快捷键只在 App 运行且单行小窗已打开时注册；隐藏后仍有效，关闭小窗或退出 App 后释放，不会凭空打开一本书。也可以点击 Dock 图标找回隐藏的小窗。
- 网页版无法注册系统全局快捷键，`Esc` 仍仅在页面获得焦点时收起正文。

## 语音

点击播放，或在菜单关闭且焦点位于阅读窗口时按空格。支持暂停、继续；更多菜单可停止。

在“…”中选择“小米 MiMo / 本地系统语音”、音色、声调及 0.5–2 倍语速。MiMo 使用已保存的语音连接；需要更换 Key 时返回主窗口的模型设置。本地声音需要系统已安装。

1.2.5 修复桌面安全策略误拦截 MiMo 本地音频地址的问题。如果旧桌面版显示“音频加载失败”，需要安装新版 App；仅重启旧版或反复修改 Key 无法解除旧策略限制。

播放结束一行后自动翻到下一行继续朗读；网络合成等待时显示小型加载图标。默认读完当前章 / 单元就停止；勾选“连续朗读下一章 / 单元”可继续往后读。

播放时手动翻页会从新位置继续；暂停时翻页不会发声。更换模型、音色或声调会停止；改变宽度或字号会暂停并重新分页。调整后再次点击播放即可。

## 收起与恢复

按 Esc 或“…”→“收起”，原文立即变成“资料 · 点击恢复”，声音停止。再次 Esc 或重新聚焦不会恢复。点击“资料 · 点击恢复”后继续显示原文，声音仍停止，需要手动播放。

可在“…”开启“失焦自动收起”，默认关闭。输入法组词期间 Esc 优先取消组词，可改用菜单收起。

## 返回与记忆

“…”→“返回完整阅读”会定位当前原文段落，可继续摘抄或写笔记。桌面关闭小窗也会重新显示主窗口。

阅读位置、字号、宽度和桌面位置会记住；重开不自动播放。桌面可选窗口置顶。首次进入可从正在朗读或选中的段落开始；否则恢复该章节 / 单元上次的单行阅读位置。

1.2.6 起，单行当前位置也保存至本机 SQLite。书架打开会回到对应章节 / 单元的完整原文位置，支持正常退出 App 后重启恢复；隐藏的主窗口不会覆盖小窗进度。详情见 [阅读位置记忆](阅读位置记忆使用说明.md)。

首版采用片段级语音同步；停止后从当前片段开头开始，未提供逐字时间戳。macOS 13 真机和实体触摸板手势仍需另行验收。
