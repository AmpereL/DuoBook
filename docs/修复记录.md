- [x] **根因**：没有常驻百分比，也没有基于原文字数的进度计算。
- [x] **修改**：当前章 / 单元按 Unicode 字符累计到当前行末计算百分比，固定两位小数；右侧常驻，菜单同步，末行 `100.00%`。翻行 / 语音推进实时更新，收起时隐藏，恢复 / 重启从原锚点重算。固定宽度及等宽数字避免位数变化挤动正文，Canvas 按剩余正文宽度分页。

## 1.2.7 · 2026-10-29

### 1. 失焦后无法快捷隐藏 / 显示单行窗口

- [x] **症状**：旧 Esc 只在页面聚焦时收起正文，其他应用聚焦后无法操作，也不会真正隐藏窗口。
- [x] **根因**：仅有渲染器键盘监听，没有系统全局注册及原生可见性切换。
- [x] **修改**：默认注册 `CommandOrControl+Shift+H`（Mac ⌘⇧H），小窗关闭 / App 退出时释放。原生隐藏不显示主窗口；显示保留位置、保持静音、不抢焦点。Dock 可找回隐藏小窗。
- [x] **验证**：系统注册成功；小窗失焦时通过相同的切换处理路径隐藏 / 显示，主窗口未弹出、其他窗口焦点保持，关闭释放键位通过。
- [ ] **限制**：尝试在 Finder 聚焦时模拟真实 ⌘⇧H，macOS 拒绝测试工具 `osascript` 发送按键（错误 1002）；跨应用的物理按键链路仍需手工验证，未修改系统权限。macOS 13 真机仍待验收。

### 2. 隐藏期间的声音与延迟播放

- [x] **症状与根因**：隐藏原生窗口不会自动结束独立的音频会话，迟到合成或跨单元自动播放可能继续。
- [x] **修改**：先主进程静音，再通知根 App 停止播放器、合成 / 预取与自动翻页，保存位置并收起正文。显示为手动恢复原文动作，保持停止；仅当前轮次确认后解除媒体静音，旧确认不会解除新隐藏状态。
- [x] **验证**：真实系统语音播放中失焦隐藏后，`speechSynthesis.speaking` 为 false；显示保留原行、无自动播放、无焦点抢占；原有 MiMo 解码回归保持通过。
- [ ] **范围限制**：不保证上游已接收的合成请求会取消，取消后的结果不继续播放。

### 3. 组合键占用与配置保存

- [x] **症状与根因**：固定组合键可能冲突，需要以系统注册结果判断是否可用。
- [x] **修改**：设置提供改键、关闭和注册状态，保存至原用户目录 `compact-shortcut.json`；先注册新键再释放旧键，失败保留原配置。录键只在小窗聚焦时抑制切换，失焦后仍可操作。
- [x] **验证**：4 项管理逻辑测试通过；桌面验证注册冲突保留原键、改键、关闭 / 启用、重启恢复和关闭释放。
- [ ] **范围限制**：网页不能提供系统全局键；关闭的小窗不会因组合键自动打开书籍。

## 1.2.5 · 2026-10-29

### 1. MiMo 已生成音频但桌面显示“音频加载失败”

- [x] **症状**：MiMo 合成成功，开始朗读仍提示“音频加载失败，请重新开始朗读”；重复开始不能解决。
- [x] **根因**：桌面后端 CSP 缺少 `media-src`，媒体请求继承 `default-src 'self'`，阻止播放器使用的本地 `blob:` 音频 URL。旧 1.2.4 包中复现到 `media-src` / `blob` 策略违规和 MediaError 4；相同真实 MiMo WAV 在 Chrome 可播放，格式为 24 kHz、单声道、16-bit PCM。
- [x] **修改**：桌面仅增加 `media-src 'self' blob:`；不放宽脚本、网络或 frame 来源，不改变本地 token 鉴权，不修改 Key。新增真实 MiMo WAV 样本与桌面语音回归脚本，保留实际播放器和解码器，不以 mock 的 `play()` 作为通过依据。
- [x] **验证**：旧包失败复现；新包真实记录音频及真实 MiMo 服务链路均验证普通阅读、单行阅读、暂停 / 继续、实际播放结束驱动翻页、Esc 停止通过，无媒体 CSP 违规。网页版也以真实 MiMo WAV 实际播放并自动进入下一段通过。后端单独验证桌面媒体策略及无 token 请求仍返回 401。
- [ ] **未验证范围**：当前桌面验证主机为 macOS 15，macOS 13 真机、Safari 与其他系统仍待验证；一次真实服务成功不保证所有网络环境和长期连续播放质量。

### 2. 普通阅读失败后重试回到第一段

- [x] **症状**：连续朗读中某个片段失败后，重新开始使用最初选择的段落，可能重复已读内容。
- [x] **根因**：开始按钮始终根据开始段落下拉框查找起点，没有使用错误快照中的失败片段索引。
- [x] **修改**：错误后直接重试从失败片段继续；用户主动更换开始段落时清除错误状态，优先遵从新选择。单行模式原有按当前位置重试行为保持。
- [x] **验证**：第二段模拟播放失败后重试仍为第二段；失败后主动改选第一段，则从第一段开始。完整语音和单行回归通过。
- [ ] **未验证范围**：仍以片段为恢复粒度，未实现逐字音频时间戳。

### 1. 不同阅读窗口同时发声

- [x] **症状**：不同阅读页的播放器独立运行，可同时发声；进入悬浮窗口也必须结束原窗口播放。
