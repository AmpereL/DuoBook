## 演示数据

- 《把一本书读懂》及其原文是为本文编写的演示书稿，章节为“带着问题进入一本书”和“把理解变成行动”。
- 第一章三个单元由人工准备，使用应用的原文边界校验和发布逻辑写入隔离数据库，用来展示已拆分界面；第二章保留未拆分状态。
- 理解、疑问、回看提醒及划线笔记均为人工填写的示例。
- 《学习的方法》是应用自带的演示书。原生单行截图使用其中的演示原文。
- 截图期间未调用线上模型，未读取用户书籍、数据库或私人 API Key。这些示例不作为模型语义拆分效果的评测。
