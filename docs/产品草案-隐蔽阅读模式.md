# 隐蔽阅读模式：产品方案草案

状态：历史外观草案，未进入 App 开发。2026-10-28 起，按用户要求调整为窗口仅一行、可拖动、支持语音与翻页的方案，当前设计见 [单行悬浮阅读产品方案](产品方案-单行悬浮阅读.md)。下文保留作为历史参考，不代表当前交付范围。现有 App 1.2.2 不因本草案改变。

## 目标与默认方案

把逻辑阅读呈现为普通资料整理工具，降低远距离观察时的阅读软件辨识度，并提供可靠的快速遮盖、无声切换和进度恢复。

推荐默认外观为“工作笔记”；提供“文档审阅”作为另一种外观。第一版优先保证长文可读，不采用把整章正文塞进表格单元格的方式。

## 外观

| 项目 | 工作笔记 | 文档审阅 |
|---|---|---|
| 页面布局 | 普通资料导航 + 正文 + 内联批注 | 文档工具栏 + 正文纸面 + 审阅侧栏 |
| 页面名称 | 用户自定义，默认“资料整理” | 用户自定义，默认“资料整理” |
| 书籍信息 | 不显示封面、作者、真实书名；目录以“资料 01”等编号呈现 | 不显示封面、作者、真实书名；用普通文档位置编号 |
| 正文 | 保留真实原文，默认系统字体、14px、普通段距 | 保留真实原文，默认系统字体、14px、纸面布局 |
| 笔记 | 内联“批注” | 侧栏“审阅记录”与批注 |
| 适用习惯 | 经常使用笔记、知识库、项目资料工具 | 经常使用文档、报告、审阅工具 |

模式内隐藏书架、逻辑地图、模型解析入口和大幅播放面板，保留读原文、前后切换、划线与批注。页面标题及网页 favicon 使用中性名称与文档图标。窗口内不显示“隐蔽”“摸鱼”“读书模式”等提示文字。

## 核心流程

从章节/阅读单元的“更多”菜单进入隐蔽阅读；进入前可预览外观、自定义名称、选择遮盖页。正常阅读和隐蔽阅读共享同一份原文与笔记。

```text
普通阅读 → 进入隐蔽阅读 → 阅读 / 划线 / 批注
                           ↓ Esc 或“收起”
                        待办遮盖页
                           ↓ 手动“返回资料”
                 恢复原段落、滚动位置与批注草稿
```

遮盖页使用用户预先填写的待办清单或空白草稿。交互原型中的任务和正文均为示例。

## 快速遮盖规则

1. 隐蔽阅读中按 Esc 或点击“收起”，立即移除原文、目录标题、划线弹框和批注区域，展示遮盖页。目标为本机交互 100ms 内完成，以实现后的测试为准，不等待网络请求。
2. 同时停止本地系统朗读和 MiMo 播放，取消后续自动播放及前端生成请求；恢复后不自动发声。已提交的上游合成不保证随前端请求取消而终止。
3. 遮盖必须保留当前书籍、章节/单元、段落、正文及目录滚动位置、未保存的批注草稿。它与“取消编辑”不同，不触发当前点击外部丢弃笔记草稿的逻辑。
4. 遮盖后再次按 Esc 不恢复；鼠标移回窗口、重新聚焦或等待一段时间也不恢复。必须由用户点击“返回资料”手动恢复。
5. 失焦自动遮盖为可选项，默认关闭，避免复制文字或切换工作窗口时频繁打断；开启后页面失焦即遮盖，重新聚焦仍保留遮盖页。
6. 输入法正在组词时，Esc 优先取消组词；按钮入口始终可用。网页快捷键只在当前页面获得焦点时有效。

## 语音、笔记与现有功能

- 进入模式时默认停止正在播放的声音。朗读需用户在模式设置中明确允许并手动开始；遮盖和失焦后不自动恢复声音。
- 原文不改写，不用模型把书变成假工作资料。章节拆分结果、历史单元和已有划线继续使用。
- 笔记复用现有精确锚点；模式切换与遮盖会暂存未保存草稿，主动保存时才写入正式笔记。
- 第一版仅覆盖章节原文及单元原文。访问书架、地图和模型设置需要明确退出模式，避免正常界面突然出现在隐蔽外壳内。
- 遮盖状态刷新或再次进入页面时优先保留遮盖页；退出模式后恢复原来的主题、标题和用户选择的图标。

## 第一版范围与验收

第一版建议交付“工作笔记”外观、快捷遮盖、待办遮盖页、恢复阅读位置与草稿、默认静音、可选失焦遮盖、中性网页标题和 favicon；“文档审阅”可随首版加入，也可作为第二步。

关键验收：长目录位置保持；批注输入中遮盖不丢字；MiMo 请求返回晚于遮盖时不播放；失焦恢复不露出正文；遮盖状态刷新不闪原文；不同书籍的位置和草稿不串；退出模式后原界面和图标恢复。

## 效果边界

模式降低的是界面辨识度。近距离阅读正文仍可能识别内容；它不隐藏网络请求、系统进程或管理软件记录。网页不能保证控制浏览器和系统其他窗口；桌面应用在 Finder 中的名字和静态图标也不随页面外观自动改变。第一版不承诺系统层面的隐身或绕过管理工具。
