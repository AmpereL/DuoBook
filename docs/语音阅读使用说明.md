# 语音阅读使用说明（1.2.1）

1. 打开书籍的章节工作台或阅读单元，在原文上方找到“语音阅读”。尚未拆分的章节也能直接听。
2. 选择“本地系统语音”或“小米 MiMo · V2.5 TTS”，再选择音色、声调和语速。可从指定段落开始。
3. 点击“开始朗读”，播放时当前原文段落会高亮。可暂停、继续或停止；读完当前页后自动结束。

本地语音使用系统已安装的声音，不需要 Key。若列表没有可用声音，请在 macOS 系统设置的辅助功能中下载朗读声音后重新打开页面。声调效果由系统声音决定，更改语速会从当前片段重新朗读。

MiMo 优先使用“模型设置 → MiMo 语音连接”中的独立地址和 Key。普通 API Key 使用 `https://api.xiaomimimo.com/v1`，Token Plan 使用其对应套餐地址。输入后可点击“测试语音连接”，再保存。Key 留空继续使用已有语音 Key；没有独立语音连接时才复用解析 Key。保存语音连接不会修改章节解析配置。

声调通过模型合成指令控制；语速在播放时即时生效。切换模型、音色或声调会停止当前朗读，再点击开始即可采用新设置。

2026-10-27 已按用户提供的新普通 API 语音 Key 完成真实合成验证。若以后提示鉴权失败，可在“MiMo 语音连接”中更新；本地语音不受影响。

网页会保存当前浏览器的朗读偏好；桌面版会保存到现有应用数据目录并在重启后恢复。朗读不会改写原文、拆分单元或笔记。

网页的语音 Key 保存在本机私有配置文件中；桌面用户保存的语音 Key 通过 safeStorage 加密。读取设置只显示“已配置”，不回显 Key。
